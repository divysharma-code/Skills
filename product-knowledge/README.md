# Product Knowledge

Plain-English reference docs on Cohere product features — the "how does this actually work"
knowledge that supports scoping, config, and bug investigation. These are **domain/feature
docs, not skills** (skills live in their own top-level folders, e.g. `cohere-bug-triage/`).

ELI5-first. | Paridhi Jain KT (Divy/Paridhi sync, 2026-07-15) |

## Conventions

- One file per feature, kebab-case (e.g. `fax-intake-config.md`).
- Start each doc with an **ELI5** section, then go deep.
- Cite the **source** (meeting, Confluence, demo) so the knowledge is traceable.
- Add a row to the **Index** table above whenever you add a doc.
