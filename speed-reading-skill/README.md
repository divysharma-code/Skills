# Speed Reading Skill

Turn a Jira ticket and its Confluence doc into a short, skimmable summary.
Seven fixed questions, plain English, nothing extra.

## Install

```
git clone https://github.com/divysharma-code/Skills.git
# copy the speed-reading-skill/ folder into ~/.claude/skills/
```

## Use it

> Speed-read this: [Jira link] and [Confluence link]

## What you get

- **Overview** — what shipped, who it's for, is it live
- **Why We Built This** — the actual problem, from the ticket
- **Impact and Outcome** — what changed, what deliberately didn't
- **Why does it matter?** — the real consequence for the reader
- **How does it work?** — the mechanism, one plain sentence
- **Where can I learn more?** — just the two source links, nothing else
- **Who is the user?** — a Role / How they use it table, roles only, no names

See [SKILL.md](SKILL.md) for the full rules.
